# finance_agent

以真实数据验证 A 股事件驱动概率预测的研究项目。当前交付是数据审计和日线基准实验，不是已验证的投资建议产品。

## 快速运行

研究命令使用 Node.js 22+。网页的 PDF 解析需要 Node.js 22.13+ 或 24+，并先运行 npm ci。本次使用 Node.js 24.14.0。基准实验本身不调用模型 API。

```powershell
git clone git@github.com:Greatisme/finance_agent.git
cd finance_agent
npm test
npm run research
```

完整流程会联网拉取腾讯日线、新浪日线和巨潮公告，缓存原始响应，然后审计、运行实验并生成报告。耗时取决于网络和公告分页量。重复运行复用缓存，**不是实时刷新命令**；需要更新快照时，将旧 `data/` 移到独立归档目录后再运行，保留旧数据以复查。修改配置后重新 collect，CLI 会拒绝配置与数据不匹配的实验。

也可以按步骤运行：

```powershell
npm run collect
npm run audit
npm run experiment
```

## 交付物

- [本次真实运行报告](reports/research-report.md)：结果、数据问题、可行性边界与下一步。
- [机器可读审计](reports/data-audit.json)：各证券覆盖、缺失、跨源差异、复权异常、公告与 PDF 抽查。
- [机器可读实验](reports/experiment.json)：各年切分、参数、校准、概率指标、分股票结果和块自助区间。
- `data/raw/`：原始 API 响应、URL、POST 参数、采集时间、SHA256；`data/documents/`：少量 PDF 原文签名抽查。
- `data/normalized/dataset.json`：本地规范化数据，含来源映射和采集错误。
- `reports/predictions.json`：逐条真实测试预测，含预测日期、入场日期、标签结束日期、真实标签与概率。

原始第三方数据、PDF 和逐条预测不提交到 Git，避免未经确认再分发授权。代码、审计摘要和实验报告提交仓库。重新联网采集可能因提供方修订而与本次快照有差别；对同一份本地快照，预测与指标为确定性结果。独立机器核验本次原始快照需要另行获得对应快照，目前仓库不包含它。

## 实验规格

参数与方便样本名单在 [config/research.json](config/research.json) 固定。本轮涵盖 2016-01-01 至 2026-10-30 的 8 只现存公司和沪深300指数，不代表完整历史 A 股市场。退市证券仅做访问探测。

目标：在 t 日收盘后预测，从下一指数交易日开盘到第 5/20 个指数交易日收盘，**未复权价格收益是否大于零**。不包含分红，不等同于总回报；没有执行策略、交易成本、涨跌停和成交能力验证。

每个测试年前留一年独立校准概率；更早年份训练。所有标签在分区边界截断隔离，标准化只拟合训练集。模型依次为：上一校准年基础上涨概率、动量逻辑回归、行情逻辑回归、行情+财报/业绩披露计数逻辑回归。后两者对比用于检查事件时间特征增益；**尚未提取财报内容或市场预期差异**。

指标包括 Brier、log loss、准确率、校准分箱、逐年/逐证券拆分，以及按日期成组的时间块自助区间。超参数在首轮指标产生前固定。后续根据当前结果调整模型时，当前测试期必须视为开发数据，重新保留最终测试期。

## 事实边界和自动门禁

- 腾讯接口字段映射为 date/open/close/high/low/volume，新浪独立供应方用于核对重叠区间。可能存在共同上游，不能以一致性代替交易所认证。
- 公告按现用名发现机构标识，随后按证券代码与机构标识精确查询，翻页直至 API 声称的总量；财报等类别由标题保守识别。不承诺历史改名、内容修订或全部事件覆盖。
- 披露记录仅按日期解释，特征到**严格晚于披露日期的下一市场交易日**才生效。不将历史检索记录伪称为已核实当年首次发布版本。
- 无大模型参与本轮特征生成；没有编造新闻、财报数值、机构/散户身份、概率或收益。
- 数据重复、非法 OHLC、跨源价格不一致、行情未覆盖截止日期、采集失败或公告截页时，CLI 非零退出，不静默生成通过的实验。
- 缺失日以指数行情日期作代理统计，尚未取得权威停复牌表，不自动填补或当作停牌。前复权仅做问题探测，模型没有使用会出现非正数的前复权序列。
- 没有 Tushare token 时不调用其授权接口，也不宣称财务结构化数据已接入。参考[官方日线文档](https://tushare.pro/document/2?doc_id=27)、[财务指标文档](https://tushare.pro/document/2?doc_id=79)。

## 源码结构

|文件|职责|
|---|---|
|`src/data.js`|缓存、来源记录、行情和公告采集|
|`src/audit.js`|完整性、数值合理性、独立供应方比对与门禁|
|`src/model.js`|仅使用历史的特征、逻辑回归、概率校准和指标|
|`src/experiment.js`|按年份滚动实验、边界标签隔离、成对比较|
|`src/report.js`|依据真实运行产出中文报告|
|`test/research.test.js`|时间泄漏、标签、指标、审计等关键正确性测试|

下一阶段优先补历史股票池、分红复权、停复牌、公告版本及财报内容；在新的独立区间与前瞻记录上验证后，再考虑网页产品和投资意见输出。

## 内置 AI 助手

在仓库根目录运行。需要可用的 Codex CLI 与 ChatGPT 登录。Windows 的 npm 全局安装可自动寻找可执行文件，其他安装方式可以通过环境变量 FINANCE_CODEX_BIN 指定 Codex 可执行文件的路径。

```powershell
npm run assistant
```

例如输入「读取数据审计，告诉我公告覆盖范围」或「运行基准实验，比较 5 日与 20 日预测」。助手通过软件工具调用采集、审计、实验和报告读取，权限覆盖当前研究流程。实验查询展示历史结果。

新会话复用本机 Codex 登录。工作目录为 `data/assistant/workspace/`，会话 ID 保存在 `data/assistant/conversation.json`。Codex 原生会话历史由本机 Codex 保存，软件的 `data/` 已被 Git 忽略。已有旧版独立会话继续使用原有目录。

再次运行 `npm run assistant` 会续接软件会话。运行 `node src/assistant.js --new` 会启用新会话，旧历史保留在本机。输入 `/exit` 退出。

[OpenAI 官方 Codex App Server 文档](https://learn.chatgpt.com/docs/app-server)

## 本地网页工作台

```powershell
npm ci
npm start
```

打开 [http://127.0.0.1:4317/](http://127.0.0.1:4317/) 查看数据审计和基准实验报告。已登录本机 Codex 时可直接使用研究助手。如果本机尚未登录，在仓库目录运行 `node src/assistant.js --login`。前端由本机 Node.js 后端提供，页面和接口使用同一个地址。

| 接口 | 用途 |
|---|---|
| `GET /api/research` | 读取研究配置、审计和实验摘要 |
| `GET /api/history` | 读取当前会话最近 50 轮网页消息 |
| `POST /api/chat` | 接收 JSON 消息 `{"message":"…"}`，以 NDJSON 返回助手回复、工具进度和完成状态 |

网页和命令行共用软件自己的 Codex 会话。网页记录保存在 `data/assistant/web-history.json`。重新加载网页后显示当前 Codex 会话中的网页消息，命令行消息由 Codex 的本地会话历史保留。使用 `FINANCE_PORT` 可调整本机端口。

个股行情支持按名称、拼音简称或代码搜索沪深 A 股。默认展示从可核实的最早日线到最新日线。可切换日 K、周 K 和月 K。横向左划看更早的行情，右划看较新的行情，也可切换窗口长度后用按钮翻看。点击 K 线可查看前收涨跌、同期沪深 300、前 20 日平均成交量对比，以及巨潮资讯近 30 日至当日公告的原文链接。助手据此分析可能的解释。最新日线可能尚未收盘，未复权价格可能受除权除息影响。公告标题和日期属于线索，无法单独确认关联或影响顺序。

行情接口为 `GET /api/stocks?q=...`、`GET /api/chart?symbol=...` 和 `GET /api/evidence?symbol=...&date=...`。网页把证券代码和交易日发给 `POST /api/chat`，由后端查询并组织证据。

波动分析目前只开放给瑞芯微（603893）、立讯精密（002475）和天奇股份（002009）。三只股票分别用东方财富半导体、消费电子、专用设备板块作行业参照，按相同交易日对比个股、行业指数和沪深 300。

公告从巨潮 PDF 提取有文字的页面，资讯从东方财富文章页读取正文。按股票及所选交易日查询近 30 个自然日至当日，最多纳入 8 条公告和 6 条资讯。资讯搜索有返回条数上限，存在历史覆盖缺口。扫描件、下载失败或截取范围不足会明确标示，当前没有 OCR。报告将条目按时间倒序展示，逐条说明事项、类别和对该股的可能影响。系统校验短引文能在对应 PDF 页或资讯段落定位，校验未通过时标为「证据不足」。行业为参考板块，同向波动与同日披露不证明因果。

运行 `npm ci` 安装网页所需的正文提取依赖。

手机端通过底部「自选」「行情」「研究」切换三个页面。点击日 K 线选择交易日，点击「分析波动」发起研究。切换自选股后可查看该股已保存的最近报告。宽屏使用三栏布局。

「行情 → 分时」由 Node 后端自动获取瑞芯微、立讯精密和天奇股份的腾讯分时行情。服务启动时取一次，之后按上海时区在周一至周五的交易时段每 20 秒更新，午休暂停，收盘后短暂补取。服务以行情源返回日期识别历史快照，尚未接入节假日交易日历。最新快照保存在 Git 忽略的 `data/intraday/`，`GET /api/intraday?symbol=...` 仅读缓存，AI 助手不参与采集。现用接口可直接请求，未确认有对外分发授权或稳定性承诺。

研究页按股票建立长期档案，目前覆盖瑞芯微、立讯精密和天奇股份。公司价值排在首位：展示已披露财务指标、报告原文（能匹配时）及最多四个历年同期报告期。之后是公告与资讯时间线、近一年公开买卖（最多 12 个龙虎榜日期、席位按需获取）及最近收盘的技术观察。点 K 线追查单日波动是辅助操作。后续新增研究报告独立存到已忽略的本地路径 data/assistant/research/，现有记录从本地会话历史读取。

日 K 主图下方的「技术指标」可以单独开关成交量、MACD (12, 26, 9) 和 Wilder RSI (14)，偏好保留在本机浏览器。日 K 上可点「多」「空」或「榜」查看证据。多空标签来自已核对原文的公告、资讯，不是全市场自动覆盖；龙虎榜不代表全部机构成交。图中阴影展示发布后最多 20 个已收盘交易日，个股与行业 1、5、20 日走势由同一交易日对照计算，不补齐缺失价格，也不据此推定因果。个股采用未复权日线。

长线档案使用 GET /api/research-context?symbol=...，事件和窗口分别使用 GET /api/events 和 GET /api/event-performance。当前档案和既有基准实验不足以验证这类证据的预测价值；只有按证据可见时间构建跨股样本，完成严格的样本外比较和校准后，才启用概率或投资意见。
